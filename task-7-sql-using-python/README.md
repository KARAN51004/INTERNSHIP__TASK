# 📊 TASK 7 — Advanced Sales Summary from SQLite Database

## 📌 Project Overview
This project demonstrates how to:
- Connect to a **SQLite** database using Python.
- Query aggregated sales data using **SQL inside Python**.
- Load query results into a **pandas DataFrame**.
- Perform basic **sales summary statistics**.
- Visualize results using **matplotlib**.
- Export both **CSV** and **PDF** reports.

The solution is implemented in a **Jupyter Notebook** with Markdown explanations, visible SQL code, and inline charts for a clear, professional presentation.
