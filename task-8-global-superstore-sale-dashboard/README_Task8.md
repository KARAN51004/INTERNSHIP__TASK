# Global Superstore Sales Analysis - Task 8

## 📌 Overview
This project presents a **simple interactive sales dashboard** built using Power BI for the Global Superstore dataset.  
It provides quick insights into sales performance by **product category, region, and time period**.

## 🛠 Tools Used
- **Power BI** for data visualization
- **Global Superstore Dataset** (Glabal superstore.csv)

## 📊 Dashboard Features
- **KPIs**: Total Sales, Total Profit, Units Sold, Number of Products, Total Customers, Total Orders
- **Visuals**:
  - Sales Trend over Months/Quarters
  - Sales by Category (Donut Chart)
  - Sales by Region (Map)
  - Top 5 States and Cities by Sales
  - Orders by Ship Mode
- **Filters**: Year, Country, State, City

## 💡 Key Insights
1. Technology category contributed the second-highest sales share (36.66%), just behind Furniture (39.75%).
2. APAC market recorded $101K in sales, being the strongest contributor overall.
3. Sales peaked in Q4 2012 with $17.5K, showing a clear seasonal trend.
4. Pune emerged as the top city by sales (32.98%) in Maharashtra.
